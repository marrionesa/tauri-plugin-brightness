## Default Permission

Default permissions for the brightness plugin.

#### Granted Permissions

All operations are enabled by default.

#### This default permission set includes the following:

- `allow-list-monitors`
- `allow-get-brightness`
- `allow-set-brightness`
- `allow-diagnose`
